## Why This Pack Matters

These sources reinforce that the CHM should be treated as a system-of-systems problem rather than a single database problem. They also make it clearer that the graph model needs to represent:

- real institutions and systems that already exist
- access modality and interoperability mode as first-class attributes
- regional and subregional support structures
- uncertainty, maturity, and source-backed claims

The main synthesis is in `notes/04-synthesis-and-next-research.md`.
